# Tyr Roadmap

This roadmap outlines the long-term development plan for the Tyr Project.

---

# Phase 0 — Foundation

- GitHub Organization
- Branding
- Governance
- Language Specification

---

# Phase 1 — Language Design

- Lexical specification
- Grammar (EBNF)
- Keywords
- Type system
- Module system
- Expressions
- Statements
- Event model
- Synchronous semantics
- Asynchronous semantics

Deliverable:

**Tyr Language Specification v0.1**

---

# Phase 2 — Compiler Frontend

- Lexer
- Parser
- AST
- Diagnostics
- Symbol tables

Deliverable:

**tyrc Frontend**

---

# Phase 3 — Semantic Analysis

- Name resolution
- Type checking
- Constant evaluation
- Validation
- Error reporting

Deliverable:

**Semantic Analyzer**

---

# Phase 4 — Hardware IR

- Hardware graph
- Optimization
- Netlist generation
- Intermediate representation

Deliverable:

**HIR**

---

# Phase 5 — Backend

- Verilog generation
- Testbench generation
- GTKWave compatibility

Deliverable:

**RTL Backend**

---

# Phase 6 — Tooling

- VS Code Extension
- Language Server
- Formatter
- Linter

Deliverable:

**Developer Tooling**

---

# Phase 7 — Documentation

- Tyr Book
- Tutorials
- Examples
- Standard library documentation

---

# Phase 8 — Version 1.0

- Stable specification
- Stable compiler
- Stable tooling
- Public release

---

# Future

Potential future work includes:

- Native simulator
- Additional backend targets
- Formal verification
- IDE integrations
- Hardware optimization passes
